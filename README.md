# ExpenseTrackerProject
A simple Java project to track personal expenses. Supports adding, deleting, and viewing expenses, plus category-wise and monthly summaries.
This project demonstrates OOP, collections, and clean modular code.

Features:
Add new expenses (amount, category, description, date)
View all recorded expenses
Delete an expense by ID
Category-wise total spending
Monthly total spending
Stores expenses in memory (can extend to file storage)


Technologies Used:
Java (Core Java)
Collections (ArrayList, HashMap)
OOP Concepts


Project Structure:
├── Expense.java
├── ExpenseManager.java
└── Main.java
